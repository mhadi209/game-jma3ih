# 🎲 تقزيرة

تطبيق ألعاب للجمعات: تكتبون أساميكم مرة وحدة وتلعبون كل الألعاب على جوال واحد، أو **أونلاين** كل واحد من جواله.

## 📲 التحميل
- **أندرويد:** روح [Releases](https://github.com/mhadi209/game-jma3ih/releases/latest) ونزّل `taqzeera.apk`.
- **من المتصفح (أي جوال، حتى آيفون):** https://mhadi209.github.io/game-jma3ih/

## 🌐 الأونلاين
من الصفحة الرئيسية اضغط **سوّ غرفة**، وأرسل الرابط لربعك. يفتحونه من المتصفح ويكتبون أساميهم ويدخلون، بدون ما ينزلون شي.
ألعاب الأونلاين: الامبوستر، ارسم وصيد الامبوستر، كود نيمز، بار الكذابين، الأغلبية، أقرب رقم، مين قالها، الجرس.

## ✏️ الملفات
| الملف | وش فيه |
|---|---|
| `topics.js` | المواضيع والكلمات وشرحها (`الكلمة = الشرح`) |
| `data.js` | أسئلة صراحة وجرأة ولو خيروك وغيرها |

| `feud.js` | أسئلة فاميلي فيود |
| `extra.js` `games3.js` `board.js` | الألعاب والأدوات |
| `online.js` | الأونلاين |
