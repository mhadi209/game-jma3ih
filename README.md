# 🎲 تقزيرة

تطبيق ألعاب للجمعات: تكتبون أساميكم مرة وحدة وتلعبون كل الألعاب على جوال واحد.

## 📲 تحميل التطبيق
روح [Releases](https://github.com/mhadi209/game-jma3ih/releases/latest) ونزّل `taqzeera.apk` (أندرويد).
كل ما يتحدث الكود، GitHub يبني نسخة جديدة وينزلها في Releases بروحه.

## 🎮 الألعاب
- 🕵️ الامبوستر (تصويت سري ونقاط)
- 🎨 ارسم وصيد الامبوستر
- 🧠 سين جيم (فريقين، ٣٠ موضوع، ٢٠٠/٤٠٠/٦٠٠، تغيير ودبل وتلميح)
- 👨‍👩‍👧 فاميلي فيود
- 🔪 المافيا
- 🔥 صراحة ولا جرأة
- 🎭 تمثيل بدون كلام
- 🚫 الكلمة الممنوعة
- 💣 القنبلة
- 🔤 إنسان حيوان نبات
- ⚡ أسئلة سريعة
- ❓ خمن الشي
- 🔄 الكلام المعكوس
- 🪑 الكرسي الساخن
- 🤔 لو خيروك
- 👉 مين أكثر واحد
- 🙈 ولا مرة

## 🧰 أدوات
🎲 النرد 3D (D4 لين D20) · 🥤 وين الكورة؟ · 🍾 لف القارورة · 🪙 ملك ولا كتابة · 👥 تقسيم الفرق

## ✏️ الملفات
- `topics.js`: المواضيع والكلمات وشرحها (`الكلمة = الشرح`)
- `data.js`: أسئلة الألعاب
- `sj.js`: أسئلة سين جيم (`النقاط | السؤال | الجواب | تلميح`)
- `feud.js`: أسئلة فاميلي فيود
- `extra.js`: الألعاب والأدوات الجديدة
