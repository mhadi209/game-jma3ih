## 🌐 الأونلاين
من الصفحة الرئيسية اضغط **سوّ غرفة**، وأرسل الرابط لربعك. يفتحونه من المتصفح ويكتبون أساميهم ويدخلون، بدون ما ينزلون شي.
ألعاب الأونلاين (كل الألعاب تقريباً): الامبوستر، ارسم وصيد الامبوستر، كود نيمز، بار الكذابين، سكرابل (حروف ومعادلات)، أونو، لودو، المافيا (التطبيق هو الراوي)، إنسان حيوان نبات (كل واحد يكتب على تلفونه وتنصحح بروحها)، سودوكو سباق، الرقم السري والكلمة السرية سباق، إكس أو، مسابقة سريعة، خمن الدولة، من سيبقى للمليون، سين جيم، فاميلي فيود، صراحة ولا جرأة، الكرسي الساخن، لو خيروك، منهو أكثر واحد، ولا مرة، تمثيل، الكلمة الممنوعة، خمن الشي، ٥ ثواني، القنبلة (تنتقل من تلفون لتلفون)، الحروف المخربطة، سلسلة الكلمات، الكلام المعكوس، الأغلبية، أقرب رقم، منهو قالها، الجرس.

## ✏️ الملفات
| الملف | ويش فيه |
|---|---|
| `topics.js` | المواضيع والكلمات وشرحها (`الكلمة = الشرح`) |
| `data.js` | أسئلة صراحة وجرأة ولو خيروك وغيرها |
| `data2.js` | كلمات الكلمة السرية، أقرب رقم، ٥ ثواني، منهو قالها، الأعلام، المليون |
| `more_*.js` | كلمات وأسئلة إضافية لكل الألعاب (تنضاف بدون تكرار) |
| `sj.js` | أسئلة سين جيم (`النقاط \| السؤال \| الجواب \| تلميح`) |
| `feud.js` | أسئلة فاميلي فيود |
| `extra.js` `games3.js` `board.js` | الألعاب والأدوات |
| `online.js` | الأونلاين |
| `online2.js` | باقي الألعاب أونلاين |
| `sfx.js` | الأصوات والمؤثرات (مركّبة بالكود بدون ملفات صوت) |
| `sudoku.js` | سودوكو |
| `scrabble.js` | سكرابل |
