# 🎉 ألعاب الجمعات

تطبيق ويب يجمع ألعاب الجمعات في مكان واحد: تكتبون أساميكم مرة وحدة وتلعبون كل الألعاب على جوال واحد.

## الألعاب
- 🕵️ الامبوستر (برا السالفة) مع "مين يسأل مين"
- 🔪 المافيا (أدوار سرية + شاشة الراوي)
- 🔥 صراحة ولا جرأة
- 🎭 تمثيل بدون كلام
- 🚫 الكلمة الممنوعة
- 💣 القنبلة
- 🔤 إنسان حيوان نبات جماد بلاد
- 🧠 سين جيم
- ❓ خمن الشي (٢٠ سؤال)
- 🔄 الكلام المعكوس (تسجيل صوت وعكسه)
- 🪑 الكرسي الساخن
- 🤔 لو خيروك
- 👉 مين أكثر واحد
- 🙈 ولا مرة

فيه 34 موضوع وأكثر من 1000 كلمة، ولكل كلمة شرح بسيط. الكلمات والأسئلة ما تتكرر لين تخلص كلها.

## تشغيله كتطبيق على الجوال
1. افتح الرابط: https://mhadi209.github.io/game-jma3ih/ في Safari (آيفون) أو Chrome (أندرويد).
2. اضغط مشاركة ← **إضافة إلى الشاشة الرئيسية**.
3. يطلع لك أيقونة مثل أي تطبيق، ويشتغل حتى بدون نت بعد أول فتحة.

## إضافة كلمات أو أسئلة
الكلمات وشرحها في `topics.js` بصيغة `الكلمة = الشرح`، والأسئلة في `data.js`.

ملاحظة: لعبة الكلام المعكوس تحتاج المايك، فلازم تفتح اللعبة من رابط https (مثل GitHub Pages).
